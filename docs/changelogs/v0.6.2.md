# v0.6.2

## Release Date

2026-11-24

## Overview

Upgrades `zod` from 3.25.76 to 4.6.7 to fix Dependabot alert GHSA-mrhx-c7xc-m3w5 (high).

## Breaking Changes

None. The public API exports only inferred types, not Zod schemas.

## What's New

Fixes GHSA-mrhx-c7xc-m3w5: validating a large array with an unbounded array schema could exhaust memory, because Zod kept an issue for every failing element. The fix is only available in `zod` 4.6.6 and later.

## Technical Details

- `zod` dependency is now `^4.6.7`.
- Single-argument `z.record(z.unknown())` calls, removed in Zod 4, now use `z.record(z.string(), z.unknown())` in `previewData.ts` and `ina/types.ts`.
