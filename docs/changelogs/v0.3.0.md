# v0.3.0

## Release Date

2026-11-18

## Overview

Adds experimental INA (Datasphere's analytical query protocol) access, transformation flow support, and a `rawRequest` escape hatch on the client. Authentication is now safe for concurrent callers: the token file is written atomically and simultaneous requests share one token refresh and one CSRF fetch. The package is now ESM-only.

## Breaking Changes

- **CommonJS output removed** — The package ships ESM only. The `require` export condition and the `main` entry (`./dist/index.cjs`) are gone, and `tsup` builds only `esm`. Any consumer that loads the library with `require()` breaks; use `import` or dynamic `import()`. Catalyst-CLI loads it by dynamic import and is unaffected.
- **`engines.bun >=1.2.0`** — `package.json` now declares a Bun engine requirement. The token cache and OAuth config reading use `Bun.file`, `Bun.write` and `Bun.sleep`, so the library needs the Bun runtime.
- **Token cache functions are async** — `loadCachedTokens` returns `AsyncResult<OAuthTokens>` and `saveCachedTokens` returns `Promise<void>` (both were synchronous). They are internal to `core/auth` and not exported from the package barrel.
- **HTTP helper module paths changed** — `core/http/session` and `core/http/helpers` are split into `refreshAccessToken`, `fetchCsrf`, `checkResponse` and `buildDatasphereUrl`. The public exports of those four names from the package entry are unchanged.

## What's New

### INA Access (Experimental)

New client methods for Datasphere's INA protocol, all marked `[EXPERIMENTAL]` and subject to change:

- **Low-level:** `inaGetServerInfo()`, `inaGetMetadata(dataSource, variables?)`, `inaQueryData(options)`.
- **High-level:** `inaListModels({ pattern? })`, `inaExploreModel(modelName, variables?)`, `inaQuery(options)` (the `simpleQuery` wrapper).
- **Hierarchy navigation** in queries (`InaHierarchyNavigation`), covered by the "INA with hierarchies" commit.
- The client fetches and caches an INA-specific CSRF token (`fetchInaCsrf`), cleared on logout.

The matching types are exported from the package entry (`InaServerInfo`, `InaQueryOptions`, `InaQueryResult`, `InaModelEntry`, and others). See `docs/ina.md`.

### Transformation Flows

- **`readTransformationFlow(name)`** and **`deleteTransformationFlow(name)`** on the client.
- **`runTransformationFlow(name)`** returns `RunTransformationFlowResult` (`{ status, runStatus }`). **The run endpoint is UNVERIFIED.** `src/core/operations/transformation-flow/run.ts` marks it `TODO(spike S0.2)`: the path (`/dwaas-core/transformationflow/space/{space}/flows/{name}/run`), the request body (`{ isDirect: true }`) and the response shape (`{ runStatus }`) are copied from replication flows by analogy and have not been exercised against a live Datasphere tenant. Do not rely on it until confirmed.
- `CsnTransformationFlow` type added; `importCsn` includes `transformationflows` when polling for imported object GUIDs, and `transformationflow` is added to the object type registry.

### `rawRequest`

`client.rawRequest(options)` sends an arbitrary request through the client's auth pipeline (access token refresh, CSRF for mutations, 403 retry) and returns the raw `Response`.

### Concurrency-Safe Authentication

- **Atomic token file** — `~/.catalyst-bdc/tokens.json` is written to a temp file and renamed into place, so a concurrent reader (this process or another) never sees a half-written file. Renames retry briefly on Windows `EPERM`/`EBUSY`/`EACCES`. Saves within a process are queued so two saves cannot drop each other's entry.
- **Single-flight refresh and CSRF** — Concurrent callers share one in-flight token refresh and one CSRF fetch instead of each starting their own. A 403 invalidates only the CSRF token that failed.
- **`client.logout()`** and `deleteCachedTokens(host)` added: logout clears the in-memory tokens and the cached entry for the host (returns whether one existed).
- **OAuth login** now clears its timeout on every exit path; previously a successful login could keep the process open until the five-minute timeout fired.

### Smaller Changes

- Network failures from requests now return as `Result` errors (`safeFetch`) instead of throwing.
- `importCsn` posts with the import name `Catalyst Import` (was `batch-import.json`) and logs counts for business layer definitions and replication and transformation flows.
- TypeScript pinned to `6.0.3`; `tsconfig.json` sets `ignoreDeprecations: "6.0"` and adds `node` types. The build target is now `esnext` (was `node20`).
- `docs/` expanded: `api.md`, `brief.md`, `ina.md`, `navigator.md` added; `README.md` and `architecture.md` reworked.

## Technical Details

### Client Module Split

`client/client.ts` is split into `client/` files: `types.ts` (`BdcClient`), `request.ts` (`executeRequest` with a `RequestAuth` seam), `ensureAccessToken.ts`, `login.ts` and `singleFlight.ts` (a generic wrapper that shares one in-flight `AsyncResult` among callers). The `ensureCsrf` module was removed in favour of client-level single-flight CSRF loading.

### New Modules

- `src/ina/` — `fetchInaCsrf`, `getServerInfo`, `getMetadata`, `queryData`, `listModels`, `exploreModel`, `simpleQuery`, `types`
- `core/operations/transformation-flow/` — `read`, `delete`, `run`
- `core/http/` — `refreshAccessToken`, `fetchCsrf`, `checkResponse`, `buildDatasphereUrl`
- `core/utils/fetch.ts` — `safeFetch`

### Tests

New unit tests `singleFlight.test.ts` and `tokenCache.test.ts` were added. They were not run as part of writing this changelog.

### Cleanup

Removed the empty `temp_package.json` and `upload.bat` (it called the gitignored `scripts/` folder). A set of `scripts-temp/` files was added and removed again within this release.

### Lockfile

`bun.lock` is added to the repository.
